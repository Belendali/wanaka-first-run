# Wanaka · First run in Studio

A clickable 1:1 of Figma section **0917** (page “Plan Mode+新手流程”,
`PWtgAaGdl6znpuQykrnIbb`): a new player's first minute in Studio.

1. **Wana says hi** — the studio dims, Wana offers a 20-second tour.
2. **Chat** — the right panel lights: talk to the AI game builder, generate assets.
3. **Scene** — the viewport and the transform tools light: place, move, rotate, scale.
4. **Plan mode** — the switch in the composer turns on; *Start!*
5. **The idea from the landing page** drops into the composer and sends itself.
6. **The crew drafts** — Planner, Artist, Developer, Tester tick through the plan.
7. **Plan · Overview** — the plan opens over everything. Genre and style menus open
   in place; picking a style re-grades the cover.
8. **Plan · Game assets** — four picks + *Generate later* per slot, five a row,
   multi-select. Hover a slot to pull out a second row and a search; *Browse all*
   opens the whole library in the slot (the others fold to a line). Search filters,
   ✕ / Esc clears, and a search that finds nothing offers *Have the Artist make it*.

The stage is the Figma frame (1920×1080) scaled to the window. The bar at the
bottom is for the demo — `?clean` hides it, `?step=1…8` opens any beat.

Run locally: `python3 serve.py` → http://localhost:8463
